# Persistent Learnings (`learning.md`)

Curated reusable knowledge, not a session log. Read this together with `agents.md` and `instructions.md` before repository changes.

## Rules for Editing This File

- **One reusable fact per line or compact bullet.**
- **Edit in place** when a new fact updates or contradicts an old one; do not keep conflicting rules.
- **Generalizable knowledge only**: capture repository conventions, user preferences, recurring mistakes, and durable corrections.
- **Prune & consolidate** when the file becomes unnecessarily large.
- **Post-processing is mandatory**: after processing a substantial repository change, persist any new reusable lesson or correction here.

---

## Repository Scope

- Rajasthan is the fixed scope for competitive-exam material under `exams/`; do not create `exams/rajasthan/`.
- Use the actual exam/post name supplied by the user as the exam archive directory when practical.
- Do not add recruitment-type or year subfolders by default; keep those distinctions in metadata/README unless explicitly requested.

## Codebase / Archive Conventions

- Preserve originals; OCR/transcriptions are derived artifacts.
- Use provenance and distinguish official/unofficial status only when supported.
- Avoid duplicate source files; use canonical locations and links.
- Keep README/index/metadata consistent with the actual archive tree.

## User Preferences

- The repository is intended to remain simple, navigable, scalable, and AI-readable.
- Supplied Hindi exam names should be preserved rather than arbitrarily translated into English folder names.

## Mistakes Made & Fixes

- Do not create redundant `rajasthan/`, recruitment-type, or year directory layers for Rajasthan exams unless explicitly requested.
- Do not claim a migration or validation succeeded until the actual GitHub tree has been checked.

## Domain Knowledge

- Competitive exam syllabi supplied as raw/OCR text should be structurally formatted while retaining the supplied substance and clearly noting editorial cleanup.
