# Contributing / Adding Academic Material

This repository is primarily a personal academic archive. Keep additions predictable and easy to maintain.

## Quick workflow

1. Identify the institution and program.
2. Identify the semester or year structure used by that program.
3. Locate the subject using its stable code and name.
4. Put the item in the correct category.
5. Rename it using the repository naming convention.
6. Preserve the original file.
7. Record provenance when the material is externally sourced.
8. Add OCR separately if useful.
9. Check for duplicates.
10. Update the relevant README/index when needed.

## Categories

- `syllabus/` — official/revised/archived syllabus files
- `previous-papers/` — examination papers organized by year/session
- `question-banks/` — collections of questions
- `notes/` — explanatory/revision study notes
- `solutions/` — worked solutions and answer keys
- `assignments/` — assignments
- `mock-papers/` — model/mock examinations
- `books/` — books/reference documents only where redistribution is permitted
- `lecture-material/` — lectures and classroom material
- `extra-material/` — useful material that does not yet justify its own category
- `ocr/` — OCR/transcriptions derived from source documents
- `images/` — supporting images/diagrams/scans
- `links/` — external resources retained at their original host

## Naming

Use lowercase paths and descriptive filenames. For papers:

`YYYY-MM-<subject-code>-<subject-slug>.pdf`

Never use ambiguous names such as `final.pdf`, `new.pdf`, or `paper1.pdf`.

## Copyright

If redistribution rights are unclear, do not upload the copyrighted file merely because it is available online. Add citation, metadata, and the original source URL instead.

## Agent changes

AI agents must read `agents.md` and `instructions.md` before modifying the repository.
