# Session Summaries (`summary.md`)

Append-only log of session execution history. Append one entry per session, newest at the bottom.

## Rules for Maintaining This File
- **ZERO DELETION / APPEND-ONLY**: Never edit, delete, or overwrite past entries.
- **Concise**: 5–10 lines per entry.
- **Code/File processes only**: Record only when files/code are created, modified, deleted, or processed. Do NOT log slash commands, mode toggles, or Q&A queries.

---

## Entry Template

```
## YYYY-MM-DD HH:MM — <One-line task title>
- Task: What was requested.
- Did: What was executed (files modified/created, decisions made).
- Result: Outcome (done / partially done / blocked).
- Open: Unfinished items or context for next session.
```
